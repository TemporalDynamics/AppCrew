Agentes

Los {{ 17 }} agentes de IA que operan el pipeline de talento de Talo.

Sourcing & Scoring
📡
DemandRadarAgent
Analiza señales del mercado para detectar empresas en expansión, nuevos lanzamientos y movimientos de talento que indican demanda de contratación.
Sourcing
🔍
TalentSourcingAgent
Busca candidatos reales en Torre.co, Brave Search y OSINT dorks. Primer agente del pipeline de búsqueda activa.
Sourcing
📊
FitScoringAgent
Puntúa candidatos contra los criterios de la búsqueda usando pesos configurables: skills, experiencia, señales de movilidad y consistencia de carrera.
Scoring
🔬
TalentSignalAgent
Detecta señales humanas y narrativas en el perfil que un score tradicional no ve: ownership, contexto de carrera, patrones de crecimiento.
Análisis
🏢
CareerContextAgent
Analiza el contexto de la empresa donde trabaja el candidato — etapa, industria, tamaño — para enriquecer el perfil de fit.
Análisis
📎
EvidenceAgent
Recopila evidencia pública del candidato: perfil web, LinkedIn, GitHub, publicaciones. Alimenta la evaluación de TalentSignal y FitScoring.
Pipeline
Outreach & Conversación
✉️
OutreachAgent
Genera drafts de email personalizados por IA usando el perfil real del candidato. Nunca envía solo — espera aprobación humana en Decision Inbox.
Outreach
💬
ConversationAgent
Califica candidatos via Telegram con 3 preguntas clave (disponibilidad, salario, motivación). Cuando el candidato está listo, envía el link de Calendly automáticamente.
Bot Telegram
↩️
ReplyAgent
Clasifica respuestas a emails en: Interesado / Pide info / No interesado / Otro. Según la intención, envía el link de Telegram, responde con info, o escala al recruiter.
Outreach
Pipeline interno
📥
IntakeAgent
Procesa el intake de nuevas búsquedas. Valida que el criterio esté completo antes de lanzar el pipeline de sourcing.
Pipeline
📋
CriteriaAgent
Genera y refina criterios de búsqueda a partir del briefing del cliente. Convierte texto libre en criterios estructurados para el pipeline.
Pipeline
🔄
NormalizationAgent
Normaliza datos de candidatos de diferentes fuentes al esquema unificado de CandidateSignal. Limpia títulos, empresas y ubicaciones.
Pipeline
🧹
DeduplicationAgent
Detecta y elimina duplicados antes de que los candidatos entren al TalentPool. Usa hash chain para garantizar integridad.
Pipeline
💾
MemoryUpdateAgent
Actualiza la memoria del sistema después de cada run: candidatos vistos, respuestas recibidas, patrones aprendidos.
Pipeline
Sistema
🧠
DoctrineKeeperAgent
Mantiene los principios y restricciones del sistema. Todos los agentes consultan la doctrina antes de actuar. Garantiza que el sistema opere dentro de los límites éticos configurados.
Sistema
🧪
TesterAgent
18 tests internos con auto-fix. Corre antes de cada deploy y verifica la integridad del pipeline completo. Detecta y corrige inconsistencias automáticamente.
QA
👔
CEOAgent
Coordina tareas de alto nivel y decisiones que requieren visión global del pipeline. Actúa como punto de escalación para los demás agentes.
Sistema
🌐
BrowserAgent
Navega páginas web para extraer información de perfiles, empresas y fuentes que no tienen API. Usa Playwright en modo headless.
Tools
📚
KnowledgeAgent
Gestiona la base de conocimiento del sistema: industrias, roles, señales de mercado y criterios históricos de búsquedas anteriores.
Sistema
